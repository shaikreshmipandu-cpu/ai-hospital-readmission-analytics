# ai-hospital-readmission-analytics
## Executive Summary
Hospital readmissions within 30 days of discharge significantly increase healthcare costs and impact patient care quality. This project leverages healthcare analytics and machine learning to identify high-risk patients, enabling proactive care interventions to reduce readmission rates.

## Project Workflow
1. **SQL Data Pipeline**: Extracted, cleaned, and prepared patient admission records.
2. **Exploratory Data Analysis (EDA)**: Analyzed patient demographics, length of stay, and clinical variables in `02_EDA_Analysis.ipynb`.
3. **Machine Learning Modeling**: Trained and evaluated classification models in `04_ML_Modeling.ipynb` to predict readmission risk scores.
